How it works, in plain English.

Read the pad

It watches exactly where each finger sits on your touchpad.

Map to the screen

Each position becomes a point on your display, rotated to match your screen’s orientation.

Inject real touch

Windows receives genuine touch input, so swipes, pinches and taps work in apps that expect a touchscreen.

Up to 10 fingers
Every contact on the pad becomes its own touch point on the screen.
Ctrl + ` toggles it
While it’s on, the normal cursor is blocked so it doesn’t fight your touches. Turn it off and your cursor returns.
Rotation-aware
Rotate your screen while it runs and the mapping follows. If portrait feels mirrored, flip one setting.
Reaches the corners
Touchpads ignore a thin strip at the edge. The corner reach slider above shows how the script makes up for it. In the script it’s called EDGE_MARGIN.

From zero to touch in four steps.

You need a Windows 10 or 11 laptop. Most modern ones work, and the questions below show how to check yours. You don’t have to type a single command.

  1. Install Python

    Python is the free program that runs touchmypad. Pick whichever way feels easier.

    From the website

    Go to python.org/downloads and click the big yellow Download button. Open the file. On the first screen, tick “Add python.exe to PATH”, then click Install Now. Choose 64-bit if it asks.

    From the Microsoft Store

    Open the Microsoft Store from your Start menu, search for “Python”, and click Get on the newest Python 3 made by the Python Software Foundation.

    Finished? Open the Start menu and type “Python”. If you see it, you’re set.

  2. Download touchmypad

    Open the GitHub page, click the green Code button, then Download ZIP. Right-click the ZIP file and choose Extract All.

    Use Git? Run this instead:

    git clone https://github.com/skykartik/touchmypad.git

  3. Start it

    Open the extracted folder and double-click touchmypad.py. A black window opens. That means it’s running, so keep it open. Then touch your touchpad once so it can find it.

    If the window flashes shut, open a terminal in that folder and run:

    python touchmypad.py

  4. Use it

    Touch the pad to tap the matching spot on the screen. Press Ctrl + ` (the key above Tab on most keyboards) to turn it off and on. Close the black window to quit.

Questions people ask

If something misbehaves, it’s almost always one of these settings in the script.

Will my touchpad work?

You need a Precision Touchpad, which most modern laptops have. To check, open Windows Settings, search for “Touchpad”, and look for the line “Your PC has a precision touchpad”.

Does it work in every game?

Only in games and apps that accept touch. Games that only understand a mouse will ignore it.

My corners are hard to reach

Raise EDGE_MARGIN in the script, for example to 0.12. Lower it if the edges feel too twitchy.

Touches are mirrored in portrait

Set FLIP_ROTATION to False to swap the two portrait directions.

Something isn’t working

Set DEBUG to True, run it again, and read what it prints.

Does it work on Mac or Linux?

No. It uses Windows touch injection, so it only runs on Windows.
